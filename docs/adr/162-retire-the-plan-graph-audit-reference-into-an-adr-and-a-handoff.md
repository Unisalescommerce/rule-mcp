# 162: Retire the plan-graph audit reference into an ADR and a handoff

- **Date**: 2026-10-24
- **Status**: accepted
- **Tags**: plans, audit, governance
- **Author**: Emiliano Pisu <pisuemiliano.1980@gmail.com>

## Context

`docs/plans/_plan-of-plans-reference.md` was audit that asked whether plan graph allowed linear implementation. It is `Status: done`, but it still carries eight follow-ups: F1 (apply contract stage by stage), F2 (Stage 3 order), F3 (toolchain additions), F4 (one id per node), F5 (five-line format), F8 (normalize status line per stage), F9 (exempt non-skill plans from checkbox assertion) and per-stage node list. plan-graph review, `docs/reviews/plan-graph.md`, is historical audit; `plan-graph` role is already in `HISTORICAL_ROLES`.

## Decision

Record audit and eight follow-ups in this ADR and in handoff 27, then delete reference file. review and historical role stay as history. skills plan test keeps retired path in its `NOT_A_PLAN` set; it reads skills plan, not reference file. release PR #9 excluded reference and is unaffected.

## Consequences

audit's open items live in handoff 27 instead of second plan file; plan-graph review remains evidence. reference file is gone; open child plans still link to it only as historical text. ADR and handoff indexes are regenerated by docs-numbering doctor.

## What would end this

audit would need file again if new stage introduced graph question ADR and handoff cannot answer. observation is plan path that no ADR or handoff entry resolves.

## Alternatives Considered

1. Keep reference (it is done and its eight follow-ups would stay split from handoff)
1. Move only follow-ups to handoff (audit evidence would be lost)
1. Delete audit and review (history would be lost)
