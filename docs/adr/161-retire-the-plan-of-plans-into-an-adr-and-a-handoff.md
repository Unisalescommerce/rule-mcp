# 161: Retire the plan-of-plans into an ADR and a handoff

- **Date**: 2026-10-24
- **Status**: accepted
- **Tags**: plans, orchestration, release, governance
- **Author**: Emiliano Pisu <pisuemiliano.1980@gmail.com>

## Context

`docs/plans/plan-of-plans.md` was level-0 orchestrator: it measured 150 plan-file instances across five branches, defined level-1 graph and stage order, and carried work from branch inventory to RuleMCP rename. Its stages 0-8 are complete, including `ge`/`dm`/`ex`/`[removed]` merges into `feat/evolution`, Stage 3.5 quick start, Stage 6 owner handover and Stage 8 rename. file is `Status: done` with zero real open checkboxes; only `- [ ]` is prose describing ten layout boxes.

open child plans are separate concern. They are 10 non-skill plans with 146 open boxes and 86 skill plans with 1,336 open boxes. plan-of-plans does not claim them as complete, and reference audit (`docs/plans/_plan-of-plans-reference.md`) is retired by ADR 162.

## Decision

Record plan-of-plans's implemented outcome in this ADR and delete plan file. Keep open child plans; handoff 27 indexes them. Delete plan-of-plans test and its cross-branch helper (`tests/plans/plan-of-plans.test.mjs`, `tests/plans/_cross-branch.mjs`); keep skills plan test. plan-of-plans was excluded from release branch, so release PR #9 is unaffected.

## Consequences

level-0 plan no longer exists as file; this ADR and handoff 27 are source for its outcome and open roadmap. open plans keep their historical links to retired path, which release tree already tolerated. two closed plan files are gone; 96 open plans remain. ADR and handoff indexes are regenerated by docs-numbering doctor.

## What would end this

plan-of-plans would be needed again if branch topology or stage order changed. observation that would reopen decision is new stage that cannot be expressed as ADR plus handoff index.

## Alternatives Considered

1. Keep plan file (it is done and stale; it would compete with handoff as source of truth)
1. Delete every plan (1,490 open items would lose their detail)
1. Keep only reference (audit is retired separately by ADR 162)
